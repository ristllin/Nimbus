# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

The short version: be respectful, assume good faith, no harassment of any
kind. Disagreements about code are fine; disrespect toward people is not.

Reports: use the private contact in [SECURITY.md](SECURITY.md) (GitHub's
report/abuse tooling also works). Maintainers will act on violations, up to
and including bans.
